# 📈 Real-Time Indian Stock Market Dashboard

A full-stack web application for monitoring Indian stock
market data with interactive charts, watchlists and
market insights.

## 🚀 Live Demo

[Open Live Dashboard](YOUR_URL)

## ✨ Features

- 📊 Market overview
- 📈 Interactive stock charts
- 🔎 Stock search
- ⭐ Watchlist
- 📉 Top movers
- 🔄 Market data updates
- 📱 Responsive interface

## 🛠️ Tech Stack

Frontend:
- React
- Vite
- Chart.js
- Axios

Backend:
- Node.js
- Express

Data:
- Yahoo Finance API

Deployment:
- Vercel

## 🏗️ Architecture

React Frontend
       ↓
Express Backend
       ↓
Market Data API
       ↓
Stock Data
